# Server Node Infrastructure

## Hardware Platform
- **Model:** HP EliteDesk 800 G3 Mini
- **OS:** Windows 10 Enterprise LTSC 2021 IoT
- **Primary Use:** Compact, low-power 24/7 home server hosting core network utilities and SDR radio decoding processes.

2. **SDRTrunk Engine:** Background P25 radio traffic logging and channel decoding.
